## 1. 产品概述

### 1.1 背景与目标

本小程序是**用户控制端**，让终端用户在手机上管理自己的智能语音辅助设备：

1. 查看设备列表 / 状态
2. 修改设备配置（音量、LED 模式、VAD 等）
 3. 查看本设备固件更新、单设备触发升级
4. 房间分组、设备绑定

### 1.2 用户画像

| 角色 | 占比 | 关心什么 |
|----|---------|----|
 | **终端用户**（如坐席 / 工厂员工） | 100% | 我的设备好不好用、音量、提示音、设备分享 |
 
  > 管理员（IT / 运维）不走小程序，使用独立的 Web 管理后台，见 PRD-cloud-platform.md §7。

### 1.3 关键约束（P0 范围）

- 微信小程序原生（不引 Taro/uni-app，避免 2 层编译）
- 必须支持微信登录（`wx.login`）
- 单用户最多绑 20 台设备
- 仅支持最新版微信（基础库 ≥3.0.0）
- UI 库用 Vant Weapp（按需引入）
 - **不**做：用户注册（用微信 openid）、支付

### 1.4 路线图

| 期 | 范围 |
|----|----|
 | **P0** | 登录、设备列表、设备详情（基础设置）、OTA 升级确认 |
 | **P1** | 房间管理、设备分享、扫码添加、消息推送 |
 
 > P2+（多语言、客服 IM 等）暂不规划，P1 收口后再讨论。

### 3.1 登录 (`pages/login/login`)

```
┌────────────────────────┐
│                        │
│   智能语音辅助设备       │
│                        │
│   ┌──────────────┐     │
│   │  微信登录     │     │ ← 一键登录按钮
│   └──────────────┘     │
│                        │
│   首次登录需同意         │
│   《用户协议》《隐私政策》 │
└────────────────────────┘
```

**流程**：
1. 用户点"微信登录"
2. `wx.login()` → `code`
3. `POST /auth/wx-login {code}` → `{token, refresh_token, user}`
4. 存 `wx.setStorageSync('jwt', token)`
5. 跳首页

**首次登录**：后端自动创建 `user` 记录（仅需 openid），返回 user 信息。

**协议弹窗**：必须用户**主动勾选**才允许登录（微信审核要求）。

**交互细节**：

| 控件 | 行为 |
|----|----|
| 音量 van-slider | 拖动时**实时**显示，松开时调 `PUT /settings`（防抖 500ms） |
| LED 模式 | 下拉选 → 立即调 `PUT /settings` |
| VAD / 打断开关 | 切换 → 立即调 `PUT /settings` |
| 房间 | 点"更换"跳房间选择页 |
| 重启设备 | van-dialog 二次确认 → `POST /command {cmd: "reboot"}` |
| 重置 Wi-Fi | van-dialog 二次确认（红色）→ `POST /command {cmd: "reset_wifi"}` |
| 恢复出厂 | van-dialog 三次确认（红色 + 输入"恢复"）→ `POST /command {cmd: "factory_reset"}` |
| 检查更新 | 调 `GET /firmwares` 找最新可升级版本 → 跳 OTA 页 |

**loading 态**：调设置时显示 van-toast "应用中..."，成功 1s 后消失，失败 van-dialog 报错。

**5s 超时**：`PUT /settings` 5s 没收到设备回执 → van-toast "设备未响应，请检查网络"。

## 5. 接口调用

见 `../protocol/rest-api-v1.0.md`。

封装在 `api/` 目录：

```js
// api/request.js - 统一拦截器
const request = (url, opts = {}) => {
  const token = wx.getStorageSync('jwt');
  return new Promise((resolve, reject) => {
    wx.request({
      url: 'https://api.example.com/api/v1' + url,
      header: { Authorization: `Bearer ${token}`, ...opts.header },
      ...opts,
      success: (res) => {
        if (res.statusCode === 401) {
          // token 过期，跳登录
          wx.reLaunch({ url: '/pages/login/login' });
          reject(res);
        } else if (res.statusCode >= 200 && res.statusCode < 300) {
          resolve(res.data);
        } else {
          wx.showToast({ title: res.data.message || '请求失败', icon: 'none' });
          reject(res);
      }
    });
  });
};

// api/device.js
export const listDevices = (filter) => request('/devices' + (filter ? `?filter=${filter}` : ''));
export const updateSettings = (deviceId, settings) => request(`/devices/${deviceId}/settings`, { method: 'PUT', data: settings });
// ...
```
