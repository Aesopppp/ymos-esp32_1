# Korvo-2 V3.1 按键控制

适用工程：`D:\ESP32-ymos-1`。目标板：ESP32-S3-Korvo-2 V3.1。SDK：工程当前使用的 ESP-IDF 6.1。

## 使用方式

| 板上标识 | 操作 | 功能 |
| --- | --- | --- |
| VOL+ | 短按 | 音量增加 5，最大 100 |
| VOL- | 短按 | 音量减少 5，最小 0（静音） |
| VOL+ / VOL- | 按住 | 首次调节后，持续按住约 0.6 秒开始连调，间隔 0.15 秒 |
| REC | 短按后松手 | 待机时跳过唤醒词，连接 ACOS 后开始监听；播放回答时停止旧回答，取消完成后继续监听 |
| REC | 长按约 2 秒 | 结束当前会话，关闭 WebSocket、停止上传和播放，回到等待唤醒 |
| SET | 长按约 3 秒 | 进入配网；已经在配网时则退出并尝试连接保存的 Wi-Fi |
| MUTE / PLAY | 任意操作 | 本版不分配功能 |

短按 REC 在松手并通过消抖后执行，以区分短按与长按。长按只执行一次，松手不再执行短按。连接中、取消回答中重复短按 REC 不会重复发起网络请求；已经在监听时短按 REC 会重新开始静默计时。

未连接 Wi-Fi 时，REC 不会启动云端对话。首次启动会话仍需等待 WebSocket 连接和认证，看到监听状态后再提问。已有的语音唤醒、语音打断和连续对话流程继续使用；无输入 60 秒会结束会话。

配网期间不接受开启对话操作，音量键可继续使用。本版没有增加菜单、关机或重启按键。

## 音量记忆

- 没有有效音量记录时使用原工程默认值 **40**。
- 优先读取现有 NVS `korvo_cfg/volume`，有效范围 0～100。
- 按键调节立即更新 Codec。停止调节约 1.5 秒后才合并写入 NVS，避免连按频繁写 Flash。
- 日志 `Volume saved: N` 表示已经保存；刚调节完立即断电，最新一次调节可能尚未保存。
- 保存失败时保留当前播放音量，每 5 秒重试保存，并记录错误。

## 配网步骤

1. 长按 SET 约 3 秒。当前对话结束，旧 Wi-Fi 的自动重连暂停，进入配网状态。
2. 手机连接 `YMOS-XXXX` 热点，密码为工程现有的 `ymos1234`。
3. 若手机没有自动打开页面，在浏览器访问 `http://192.168.4.1/`。
4. 点击“扫描 Wi-Fi”，选择网络，输入密码并保存。设备退出热点模式并尝试连接该网络。
5. 获得 IP 后回到等待唤醒，可使用唤醒词或短按 REC 开始对话。

再次长按 SET 可以退出配网；10 分钟未完成配网也会退出，并尝试连接保存的网络。进入/退出配网本身不删除凭据。新配置连接失败时恢复本轮提交前的凭据并重新进入配网，可修正密码，或长按 SET 退出后连接旧网络。旧凭据备份保存在 RAM，仅用于本次运行期间的失败回滚，不是断电事务备份。

## 实现位置与维护边界

沿用原工程的 C 服务模块和事件总线，业务状态切换仍由 `app_main` 主任务串行执行。

| 文件 | 职责 |
| --- | --- |
| `main/button_policy.h` | ADC 电压区间、40 ms 消抖、短按/长按/重复判定、音量步进；不依赖 RTOS |
| `main/button_service.c/.h` | ADC1_CH4 采样与校准，4 次采样取平均，每约 10 ms 扫描；只发按键动作事件 |
| `main/event_bus.h` | `EV_BUTTON_*` 事件，无借用缓冲区的 payload |
| `main/app_main.c` | 开启/结束会话、手动打断、配网切换、音量加载与延迟保存 |
| `main/audio_out.c/.h` | 持输出互斥锁设置 ES8311 音量，记录当前音量；不负责 NVS |
| `main/wake_word.c/.h` | 手动打断前保护现有预录音，复用取消完成后的补传流程 |
| `main/wifi_service.c/.h` | 主动停止时关闭自动重连，恢复时重启 STA；60 秒未获取 IP 则报告失败 |
| `main/provisioning_service.c/.h` | 热点/HTTP/DNS 生命周期、提交与失败回滚；获得 IP 后确认配网成功 |
| `tests/button_policy_checks.cc` | 针对生产判定逻辑的编译期回归 |

手动打断沿用 `ws_service_cancel_response()` 和原有 `CANCELLING → LISTENING` 流程，未增加 ACOS 协议。播放期间已有约 1.5 秒滚动预录音，手动打断时保护缓存，取消等待期间继续采集，随后先补传句首再接实时音频。实际取消耗时仍受服务端应答影响。

`session_requested` 表示主任务仍希望维持会话。手动结束、静默超时、进入配网时清除它和所有重试期限，迟到的 WS 事件不能重新开启会话。WebSocket 原有的连接代次过滤继续生效，配网提交也带代次，避免旧提交影响新一轮配网。

## 硬件与判定限制

Korvo-2 的六个用户按键共用 GPIO5 / ADC1_CH4 电阻梯形网络。无需新增 GPIO 连线。电压区间采用乐鑫 ESP-BSP Korvo-2 驱动定义：

| 按键 | 校准后电压区间（mV） |
| --- | --- |
| REC | 2310～2510 |
| MUTE | 1880～2080 |
| PLAY | 1550～1750 |
| SET | 1010～1210 |
| VOL- | 720～920 |
| VOL+ | 280～480 |

≥2700 mV 作为松手；区间外视为不确定电压。采用 ADC curve-fitting 校准，不用原始 ADC 数值直接冒充毫伏。若 ADC 初始化或校准失败，会打印 `Buttons unavailable`，其余功能继续启动。

上电按住键时先等待松手。检测到未松手就换键或持续异常电压时取消本次动作，稳定松手后才恢复。**不支持同时按多个键**：电阻网络的组合电压可能落入另一个有效区间，软件无法保证辨别所有组合。

官方依据：[ESP-BSP Korvo-2 按键驱动（固定版本）](https://github.com/espressif/esp-bsp/blob/f259a6abd5808019b1903a422092a4234ca95a51/bsp/esp32_s3_korvo_2/src/bsp_button.c)。

## 验证与实板验收

在工程匹配的 ESP-IDF 终端，运行以下编译期回归和固件构建：

```powershell
xtensa-esp32s3-elf-g++ -std=c++17 -Wall -Wextra -Werror -fsyntax-only tests/button_policy_checks.cc tests/audio_preroll_checks.cc tests/barge_in_guard_checks.cc
idf.py build
```

编译期断言覆盖电压边界、消抖、短按、长按单次触发、长按松手不触发短按、音量连发/限幅、无功能按键、上电按住、异常换键和毫秒回绕。它们不替代 ADC、电声、NVS 断电保存或网络实板测试。

烧录新固件后依次验证：

1. 确认日志出现 `ADC keys ready` 和正确的启动音量。
2. 分别短按、长按 VOL+/VOL-，验证步进、限幅；等 `Volume saved` 后重新上电确认音量恢复。
3. 不说唤醒词，短按 REC；确认进入监听并能完成问答。
4. 回答播放期间短按 REC 并说一段短句；确认旧回答停止、句首补传、随后能正常回答。重复至少 5 次。
5. 在监听、播放、连接中分别长按 REC，确认回到待机，不会被迟到的错误重新拉起；再次短按可正常开始。
6. 在待机与播放期间分别长按 SET，确认热点页面可用；连续进出至少 5 次，并在扫描期间退出一次，确认热点和旧网络恢复正常。
7. 提交正确和错误的 Wi-Fi 凭据，检查获得 IP、失败回滚与再次配网；空置配网页面 10 分钟确认超时恢复。
8. 确认 MUTE/PLAY 无业务动作、上电按住 REC/SET 不误触发；复测唤醒词、语音打断和 60 秒静默待机。

本轮没有烧录或进行实板测试，以上硬件和交互效果需要在目标板上确认。
